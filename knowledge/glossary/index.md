# Glossary

* [AI Inference](ai-inference.md) — the capability that turns unstructured input into a judgement (score, classification, prediction, generated content).
* [Request Handler](request-handler.md) — the HTTP layer turning an incoming request into a service call and a result into a response (identity, decode, validation, error mapping).
* [Telemetry](telemetry.md) — the measured runtime health of the platform: runtime memory/GC, database pool state, HTTP request counts, and latency percentiles.
