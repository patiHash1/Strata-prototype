# Strata API Documentation

**Strata** is a frontier ERP-CRM Hybrid platform — a direct competitor to Odoo. This documentation covers the Strata API, architecture, development setup, and contribution guidelines.

## Project status

The project is in early prototype stage. The API is under active development and breaking changes should be expected until version 1.0.0.
